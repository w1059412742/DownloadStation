1. 设计理念 (Design Philosophy)
•	克制与留白 (Less is More)： 放弃边框线，依靠充足的留白 (Spacing) 和柔和的背景色差来划分区域。
•	内容优先 (Content First)： UI 应当隐退，突显软件图标、名称和排版。
•	优雅灵动 (Fluid & Elegant)： 拒绝生硬的颜色切换，所有悬停、展开、页面跳转均需包含 0.2s - 0.3s 的缓动过渡动画 (Ease-in-out)。
•	扁平化导航 (Flat Navigation)： 彻底抛弃深层级的树状目录，采用“平铺胶囊式”或“双重顶导”实现 1-2 级分类的高效检索。
________________________________________
2. 全局设计系统 (Design System)
在开始写 Vue 组件前，请先在全局 CSS (推荐使用 Tailwind CSS) 中定义以下规范：
2.1 色彩规范 (Color Palette)
摒弃大红大绿，采用高级灰调与单一强调色。
•	背景色 (Background)：
o	亮色模式：纯白 #FFFFFF (卡片/内容区) / 极浅灰 #F8FAFC (底层背景)。
o	暗色模式：深空灰 #0F172A (底层背景) / 炭灰 #1E293B (卡片/内容区)。
•	文字色 (Typography Colors)：
o	一级标题 (H1/H2)：纯黑 #0F172A (亮) / 纯白 #F8FAFC (暗)。
o	正文描述 (Body)：浅石板灰 #64748B (亮) / #94A3B8 (暗)。
•	强调色 (Primary Accent)：
o	推荐使用 克莱因蓝 #0055FF 或 苹果靛蓝 #5E5CE6。仅用于主【下载】按钮、选中状态的分类标签、以及文字超链接。
2.2 阴影与圆角 (Shadows & Radius)
•	无边框主义： 卡片默认不要 border: 1px solid，而是使用弥散阴影。
•	卡片阴影 (Card Shadow)： box-shadow: 0 10px 40px -10px rgba(0,0,0,0.08); (极大、极柔和的阴影)。
•	圆角规范 (Border Radius)：
o	按钮、小标签 (Pills)：8px 或 9999px (全圆角)。
o	软件展示卡片：16px。
o	大型对话框/详情图片：24px。
2.3 字体排版 (Typography)
•	字体族 (Font Family)： Inter, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif; (确保在 Windows 和 Mac 上都呈现原生高级感)。
•	字重对比： 标题使用 font-weight: 700 (Bold)，描述使用 font-weight: 400 (Regular)。拒绝中庸的 500/600。
________________________________________
3. 前台展示页设计规范 (Public UI)
前台布局采用 全宽顶部导航 + 居中限制宽度的内容区（最大宽度 max-width: 1200px），确保在大屏显示器上不会显得松散。
3.1 顶部导航栏 (Header)
•	视觉效果： 采用“毛玻璃”特效 (backdrop-filter: blur(12px); background: rgba(255,255,255,0.7)）。向下滚动页面时，导航栏吸顶，底层文字隐约透出。
•	布局 (三段式)：
o	Left: 极简的 Logo + 站点名称（如：My App Store，粗体）。
o	Center: 搜索框。宽大、圆角、浅灰背景。无边框。Placeholder：“搜索软件、工具或系统...”。
o	Right: 极简的图标按钮（太阳/月亮切换暗黑模式）。
3.2 软件大厅 (首页 Index)
•	头图欢迎区 (Hero Section)：
o	顶部留白 80px。
o	居中一行大字标题：“精选数字资产与工具库”（字体大小 36px，加粗）。
o	下方一行灰色小字：“存放在 NAS 中的私人软件仓库，极速、纯净、随时可用。”
•	分类导航区 (Category Pills) - 扁平化设计的核心：
o	一级分类： 居中横向排列的一排文字。选中项字体加粗，底部有一小段强调色的下划线（带滑动动画）。
o	二级分类： 一级分类下方，是一排灰色的“胶囊按钮 (Pills)”。如选中的一级分类是“开发工具”，下方出现胶囊：全部 IDE 数据库 运维工具。选中胶囊背景变为强调色，文字变白。
•	软件列表区 (Bento Box 网格)：
o	采用 CSS Grid 布局（PC 端 4 列，平板 2 列，手机 1 列），列间距 gap: 24px。
o	卡片微交互： 默认平铺无边框。鼠标悬停 (Hover) 时：卡片整体向上浮动 4px (transform: translateY(-4px))，弥散阴影加深。
o	卡片内容排版：
	左上角：64x64px 软件 Icon，大圆角。
	下方：18px 粗体软件名。
	再下方：两行浅灰色简介（超出显示 ...）。
	底部：极小的平台图标（如 Windows 徽标）排列在左侧，右侧浅灰色显示 ↓ 1.2k (下载量)。
3.3 软件详情页 (Detail)
•	阅读区限宽： 详情页主体内容限制在 max-width: 800px，居中排版，提供沉浸式的阅读体验。
•	环境光背景 (Ambient Header)： 提取软件 Icon 的主色调，作为页面顶部的极大且极模糊的背景光晕，营造苹果发布会般的高级感。
•	基础信息区： 巨大的软件 Icon (120x120px)，紧跟 40px 大小的软件名称。下方排列一排分类、平台、官网的灰色小胶囊标签。
•	Markdown 正文区 (Prose)：
o	行高设定为 1.75。段落间距留足。
o	引用块 (<blockquote>) 使用左侧一条强调色的粗线。
o	代码块提供深色背景，右上角自带“一键复制”隐形按钮（Hover时浮现）。
•	版本与下载区 (卡片栈排列)：
o	最新版本 (高亮呈现)： 单独一个带有细微主色边框的卡片。
	左侧显示大号版本号（如 v2023.2.1），下方灰色小字显示更新日期与大小。
	右侧是一个圆角矩形的实心强调色大按钮[ 立 即 下 载 ]。
	按钮下方默认隐藏哈希值，点击 [校验码] 优雅展开。
o	历史版本 (折叠收起)： 下方以时间线 (Timeline) 或紧凑的列表形式排列。默认折叠，提供 查看全部历史版本 (12) 的灰色文字按钮。

4. 后台管理页设计规范 (Admin UI)
后台面向站长本人，设计重点是高信息密度、极简操作流、防疲劳。
4.1 极客登录入口 (Login)
•	视觉： 纯黑或纯白背景，页面正中心只有一个输入框。
•	交互： 没有“用户名”，没有“验证码”，甚至可以没有“登录按钮”。输入框只有底部一条灰线，Placeholder 提示 Enter Passcode。输入正确的全局密码后，按下 Enter 键，页面以极快的淡出动画直接进入后台。
4.2 整体布局 (Layout)
•	侧边栏 (Sidebar)： 极窄（仅显示图标）或较窄的左侧栏。图标使用线条风格（如 Lucide Icons）。
•	内容区 (Main)： 纯白背景，顶部提供面包屑导航。
4.3 扫描入库流程界面 (核心交互 - 神技页)
这是体现 NAS 特色的核心页面，必须设计得无比顺滑。
•	界面布局： 左右分栏或抽屉式 (Drawer) 设计。
•	左侧 (孤儿文件列表)：
o	点击顶部的 [ 🔄 扫描 NAS 目录 ] 按钮后（带旋转动画）。
o	列表中出现扫描到的未绑定文件：如 idea-2023.exe。
•	右侧 / 抽屉 (一键入库操作区)：
o	点击文件行的 [ 入库 ] 按钮，右侧滑出抽屉层。
o	表单极简化： 文件名和大小已自动填充并置灰。
o	只需选择：【归属软件】(支持拼音搜索下拉)、输入【版本号】。
o	下方提供一个极简的 Markdown 文本框用于填写“更新日志”。
o	底部大按钮：[ 保存并自动计算校验码 ]。点击后关闭抽屉，左侧列表项伴随绿色的成功动画消失。

•	字体族 (Font Family)： Inter, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif; (确保在 Windows 和 Mac 上都呈现原生高级感)。
•	字重对比： 标题使用 font-weight: 700 (Bold)，描述使用 font-weight: 400 (Regular)。拒绝中庸的 500/600。

3. 前台展示页设计规范 (Public UI)
前台布局采用 全宽顶部导航 + 居中限制宽度的内容区（最大宽度 max-width: 1200px），确保在大屏显示器上不会显得松散。
3.1 顶部导航栏 (Header)
•	视觉效果： 采用“毛玻璃”特效 (backdrop-filter: blur(12px); background: rgba(255,255,255,0.7)）。向下滚动页面时，导航栏吸顶，底层文字隐约透出。
•	布局 (三段式)：
o	Left: 极简的 Logo + 站点名称（如：My App Store，粗体）。
o	Center: 搜索框。宽大、圆角、浅灰背景。无边框。Placeholder：“搜索软件、工具或系统...”。
o	Right: 极简的图标按钮（太阳/月亮切换暗黑模式）。
3.2 软件大厅 (首页 Index)
•	头图欢迎区 (Hero Section)：
o	顶部留白 80px。
o	居中一行大字标题：“精选数字资产与工具库”（字体大小 36px，加粗）。
o	下方一行灰色小字：“存放在 NAS 中的私人软件仓库，极速、纯净、随时可用。”
•	分类导航区 (Category Pills) - 扁平化设计的核心：
o	一级分类： 居中横向排列的一排文字。选中项字体加粗，底部有一小段强调色的下划线（带滑动动画）。
o	二级分类： 一级分类下方，是一排灰色的“胶囊按钮 (Pills)”。如选中的一级分类是“开发工具”，下方出现胶囊：全部 IDE 数据库 运维工具。选中胶囊背景变为强调色，文字变白。
•	软件列表区 (Bento Box 网格)：
o	采用 CSS Grid 布局（PC 端 4 列，平板 2 列，手机 1 列），列间距 gap: 24px。
o	卡片微交互： 默认平铺无边框。鼠标悬停 (Hover) 时：卡片整体向上浮动 4px (transform: translateY(-4px))，弥散阴影加深。
o	卡片内容排版：
	左上角：64x64px 软件 Icon，大圆角。
	下方：18px 粗体软件名。
	再下方：两行浅灰色简介（超出显示 ...）。
	底部：极小的平台图标（如 Windows 徽标）排列在左侧，右侧浅灰色显示 ↓ 1.2k (下载量)。
3.3 软件详情页 (Detail)
•	阅读区限宽： 详情页主体内容限制在 max-width: 800px，居中排版，提供沉浸式的阅读体验。
•	环境光背景 (Ambient Header)： 提取软件 Icon 的主色调，作为页面顶部的极大且极模糊的背景光晕，营造苹果发布会般的高级感。
•	基础信息区： 巨大的软件 Icon (120x120px)，紧跟 40px 大小的软件名称。下方排列一排分类、平台、官网的灰色小胶囊标签。
•	Markdown 正文区 (Prose)：
o	行高设定为 1.75。段落间距留足。
o	引用块 (<blockquote>) 使用左侧一条强调色的粗线。
o	代码块提供深色背景，右上角自带“一键复制”隐形按钮（Hover时浮现）。
•	版本与下载区 (卡片栈排列)：
o	最新版本 (高亮呈现)： 单独一个带有细微主色边框的卡片。
	左侧显示大号版本号（如 v2023.2.1），下方灰色小字显示更新日期与大小。
	右侧是一个圆角矩形的实心强调色大按钮[ 立 即 下 载 ]。
	按钮下方默认隐藏哈希值，点击 [校验码] 优雅展开。
o	历史版本 (折叠收起)： 下方以时间线 (Timeline) 或紧凑的列表形式排列。默认折叠，提供 查看全部历史版本 (12) 的灰色文字按钮。

4. 后台管理页设计规范 (Admin UI)
后台面向站长本人，设计重点是高信息密度、极简操作流、防疲劳。
4.1 极客登录入口 (Login)
•	视觉： 纯黑或纯白背景，页面正中心只有一个输入框。
•	交互： 没有“用户名”，没有“验证码”，甚至可以没有“登录按钮”。输入框只有底部一条灰线，Placeholder 提示 Enter Passcode。输入正确的全局密码后，按下 Enter 键，页面以极快的淡出动画直接进入后台。
4.2 整体布局 (Layout)
•	侧边栏 (Sidebar)： 极窄（仅显示图标）或较窄的左侧栏。图标使用线条风格（如 Lucide Icons）。
•	内容区 (Main)： 纯白背景，顶部提供面包屑导航。
4.3 扫描入库流程界面 (核心交互 - 神技页)
这是体现 NAS 特色的核心页面，必须设计得无比顺滑。
•	界面布局： 左右分栏或抽屉式 (Drawer) 设计。
•	左侧 (孤儿文件列表)：
o	点击顶部的 [ 🔄 扫描 NAS 目录 ] 按钮后（带旋转动画）。
o	列表中出现扫描到的未绑定文件：如 idea-2023.exe。
•	右侧 / 抽屉 (一键入库操作区)：
o	点击文件行的 [ 入库 ] 按钮，右侧滑出抽屉层。
o	表单极简化： 文件名和大小已自动填充并置灰。
o	只需选择：【归属软件】(支持拼音搜索下拉)、输入【版本号】。
o	下方提供一个极简的 Markdown 文本框用于填写“更新日志”。
o	底部大按钮：[ 保存并自动计算校验码 ]。点击后关闭抽屉，左侧列表项伴随绿色的成功动画消失。
1. 设计理念 (Design Philosophy)
•	克制与留白 (Less is More)： 放弃边框线，依靠充足的留白 (Spacing) 和柔和的背景色差来划分区域。
•	内容优先 (Content First)： UI 应当隐退，突显软件图标、名称和排版。
•	优雅灵动 (Fluid & Elegant)： 拒绝生硬的颜色切换，所有悬停、展开、页面跳转均需包含 0.2s - 0.3s 的缓动过渡动画 (Ease-in-out)。
•	扁平化导航 (Flat Navigation)： 彻底抛弃深层级的树状目录，采用“平铺胶囊式”或“双重顶导”实现 1-2 级分类的高效检索。

2. 全局设计系统 (Design System)
在开始写 Vue 组件前，请先在全局 CSS (推荐使用 Tailwind CSS) 中定义以下规范：
2.1 色彩规范 (Color Palette)
摒弃大红大绿，采用高级灰调与单一强调色。
•	背景色 (Background)：
o	亮色模式：纯白 #FFFFFF (卡片/内容区) / 极浅灰 #F8FAFC (底层背景)。
o	暗色模式：深空灰 #0F172A (底层背景) / 炭灰 #1E293B (卡片/内容区)。
•	文字色 (Typography Colors)：
o	一级标题 (H1/H2)：纯黑 #0F172A (亮) / 纯白 #F8FAFC (暗)。
o	正文描述 (Body)：浅石板灰 #64748B (亮) / #94A3B8 (暗)。
•	强调色 (Primary Accent)：
o	推荐使用 克莱因蓝 #0055FF 或 苹果靛蓝 #5E5CE6。仅用于主【下载】按钮、选中状态的分类标签、以及文字超链接。
2.2 阴影与圆角 (Shadows & Radius)
•	无边框主义： 卡片默认不要 border: 1px solid，而是使用弥散阴影。
•	卡片阴影 (Card Shadow)： box-shadow: 0 10px 40px -10px rgba(0,0,0,0.08); (极大、极柔和的阴影)。
•	圆角规范 (Border Radius)：
o	按钮、小标签 (Pills)：8px 或 9999px (全圆角)。
o	软件展示卡片：16px。
o	大型对话框/详情图片：24px。
2.3 字体排版 (Typography)
•	字体族 (Font Family)： Inter, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif; (确保在 Windows 和 Mac 上都呈现原生高级感)。
•	字重对比： 标题使用 font-weight: 700 (Bold)，描述使用 font-weight: 400 (Regular)。拒绝中庸的 500/600。
