# F-CAT-001 访客检索、详情与分享

状态：approved
涉及组件：SPA Home、SoftwareDetail、公共查询API
确认依据：2026-10-20 用户评论 `01a159cc-a87d-7c44-b4d2-9c789c2639ac`，批准[接入记录 D1](../../changes/CHG-2026-001-sdd-adoption/change.md#本轮真实目标决定)，采用固定快照中已核实且无例外的浏览行为。

## 目标与范围

供访客按关键词、分类和单平台查找已发布软件，查看详情、全部可见版本并分享短链接。旧PRD首页“最新/最热”排序切换、深层分类逐层导航、日志Markdown和版本折叠等未完成目标见接入记录B09，不推定已实现或取消；API支持排序参数不代表首页已有切换控件。失败界面、并发请求乱序和下载计数可靠性不在本次采用范围。

## 功能规则

### REQ-CAT-001-001
对于合法无环分类树和有效分页参数，公共查询必须将非空关键词按名称或简介包含匹配，将分类限制为所选分类及全部后代，将平台限制为所选单一平台；多个条件必须共同成立。无筛选值时该条件不限制结果。公共列表不提供标签过滤。

### REQ-CAT-001-002
服务必须先对非null的`sortBy`转小写，再与`popular`比较；归一化结果相等时必须按软件总下载数字段倒序、再创建时间倒序，故`popular`、`POPULAR`和`Popular`均进入该分支。参数缺省/null、空串或归一化后不等于`popular`时，必须按软件更新时间倒序、再创建时间倒序。此规则与固定快照的`sortBy?.ToLower()`一致，不新增排序选项。服务必须返回过滤后的总数及指定页数据，API默认第1页每页20条；SPA首页必须默认popular、每页15条，检索回车或切换筛选后从第1页加载，加载更多追加下一页。同排序键的最终顺序不作额外承诺。

### REQ-CAT-001-003
软件详情必须展示名称、简介、分类、单平台、标签、HTML介绍及已提供的图标和官网信息；必须展示全部可见版本，不限于最新三版。版本日志必须按普通文本展示；页面SHA256采用截断显示，HashStatus=Done的“已验证”标记仅表示哈希任务完成，不表示安装包安全。

### REQ-CAT-001-004
`/software/:id`和`/s/:id`必须指向同一软件详情；分享操作必须尝试将当前站点`/s/:id`链接复制到剪贴板。分享模式必须隐藏普通详情的部分导航。复制成功必须提示链接已复制；剪贴板权限或调用失败必须提示复制失败、手动复制当前地址，不得提示成功。

## 各端行为与契约

入口：`/`、`/software/:id`、`/s/:id`；API契约源为`Controllers/Public/SoftwaresController.cs`、`DownloadController.cs`及软件/版本响应DTO；消费者为`views/public/Home.vue`、`SoftwareDetail.vue`和`AppHeader.vue`。API的递归分类筛选不代表首页能逐层选择任意深度。

富文本内容规则引用[软件档案](../software/F-SW-001-software.md)，采用HTML格式不批准未清理脚本或任意可执行内容。数据请求失败和同组件参数切换的现状缺陷见B07/B08，不能将静默失败定义为正确行为。

## 验收条件

### AC-CAT-001-001（验证 REQ-CAT-001-001）
前提：父分类下有子孙分类，各有不同平台和名称/简介的软件。
操作：组合父分类、平台、关键词检索；再清除条件。
结果：组合查询只含同时满足条件的已发布软件，包含后代分类命中项；清除条件恢复相应范围，无匹配时总数及本页为空。

### AC-CAT-001-002（验证 REQ-CAT-001-002）
前提：匹配数据超过两页，排序字段有可区分值，数据在请求间不变。
操作：通过API分别以`popular`、`POPULAR`、`Popular`查询，再以缺省/null、空串及不匹配值查询；首页加载更多后切换筛选。
结果：前三种参数均按总下载数字段、创建时间倒序，后三类均按更新时间、创建时间倒序；页数据和总数对应同一过滤范围。首页初始15条，追加下一页，切换筛选后重置第1页；本AC不表示首页已有排序切换控件。

### AC-CAT-001-003（验证 REQ-CAT-001-003）
前提：已发布软件有四个可见版本和一个隐藏版本，含标签及HTML介绍。
操作：打开详情。
结果：展示档案内容和四个可见版本，隐藏版本不展示；日志为普通文本，哈希展示不宣称安全扫描通过。

### AC-CAT-001-004（验证 REQ-CAT-001-004）
前提：浏览器允许剪贴板访问，软件已发布。
操作：普通详情执行分享并打开复制链接。
结果：链接为当前站点`/s/:id`，打开后展示相同软件，采用分享模式导航。另拒绝剪贴板权限时，提示复制失败及手动复制，不提示成功。
