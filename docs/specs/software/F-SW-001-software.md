# F-SW-001 软件档案与内容维护

状态：approved
涉及组件：管理软件列表、编辑页、富文本编辑器、软件和图片API
确认依据：2026-10-20 用户评论 `01a159cc-a87d-7c44-b4d2-9c789c2639ac`，批准[接入记录 D1](../../changes/CHG-2026-001-sdd-adoption/change.md#本轮真实目标决定)，含单平台、多标签和HTML介绍。

## 目标与范围

维护软件基本信息、发布状态、图标及HTML介绍。软件和文件的破坏性删除、HTML安全策略、非法输入及同名竞争的现状不在采用范围，见B04/B06/B07；独立截图相册与灯箱保留未来目标。有效输入指页面要求的非空名称、已存在平台和有效可选关联，非任意HTTP载荷。

## 功能规则

### REQ-SW-001-001
管理员保存有效软件档案时，系统必须保存名称、简介、HTML介绍、图标路径、官网、一个可选分类、一个可选平台及多个标签。创建未指定状态时必须为Published；更新必须替换标签集合而不是仅追加，空集合清除关联。空白分类/平台引用必须存为无关联；字典删除导致的平台空值不改变软件身份。

### REQ-SW-001-002
后台列表必须包括Draft和Published，支持分类、平台、标签、关键词联合过滤，标签条件为软件含指定标签；分类/平台/关键词、排序和分页采用[访客检索 REQ-CAT-001-001/002](../catalog/F-CAT-001-browse.md)的共同语义，排序参数大小写归一化及回退分支统一引用REQ-CAT-001-002。后台不受公共接口“无标签过滤”限制，后台API默认每页20条。后台详情和更新/状态切换目标不存在时必须返回不存在；有效状态切换必须持久化Draft=0或Published=1。

### REQ-SW-001-003
软件编辑页必须在名称或平台缺失时阻止保存；保存前必须尝试同平台同名预查并在命中时阻止该次保存，编辑时排除自身。预查不是数据库唯一约束，不能据此承诺并发去重。富文本编辑器必须输出HTML并支持将上传图片插入介绍；图标与介绍图片复用图片上传能力。

### REQ-SW-001-004
对于已认证、非空且在请求10MB限制内的图片上传，系统必须按日期目录和GUID文件名保存并返回`/uploads/images/...` URL；空文件必须拒绝。图片存放于独立UploadBasePath，不是安装包软件库。采用HTML和图片能力不允许将未验证的内容安全性写为已满足。

### REQ-SW-001-005
新建软件并同时添加版本时，编辑页必须先保存软件，再上传或绑定文件；若第二步失败，必须保留已创建的软件并提示软件已保存但版本步骤失败，不得将两步表现为整体成功。

## 各端行为与契约

契约源为`Controllers/Admin/AdminSoftwaresController.cs`、软件请求/响应DTO和`SoftwareService`；消费者为`views/admin/Softwares.vue`、`views/admin/SoftwareDetail.vue`、`components/common/RichEditor.vue`及公共详情。图片访问由`Program.cs`静态文件映射提供。结构字段留在DTO，不另抄一份API规范。

## 验收条件

### AC-SW-001-001（验证 REQ-SW-001-001）
前提：有效分类、平台和两个标签存在。
操作：创建含HTML的软件；更新时更换标签集合，再清空集合。
结果：档案字段和单平台保存，默认Published；更新只保留新标签，清空后无标签关联。

### AC-SW-001-002（验证 REQ-SW-001-002）
前提：有Draft和Published软件以及有效标签。
操作：后台API联合筛选，使用AC-CAT-001-002的排序参数组查询；切换有效软件状态，读取和更新不存在的软件。
结果：后台可查两类状态，筛选共同成立；排序参数各分支结果与REQ-CAT-001-002相同；状态持久化，不存在目标返回不存在。本AC不表示后台页面新增排序控件。

### AC-SW-001-003（验证 REQ-SW-001-003）
前提：软件编辑页及同平台同名记录存在。
操作：缺名称/平台保存、预查命中后保存；编辑原记录且排除自身；插入已上传介绍图片。
结果：前两种保存被阻止，自身不构成重名；编辑器输出包含图片URL的HTML。

### AC-SW-001-004（验证 REQ-SW-001-004）
前提：隔离图片目录可写，管理员已登录。
操作：上传非空小图片及空文件。
结果：前者存为日期/GUID路径并返回可访问URL；后者拒绝，不产生图片。

### AC-SW-001-005（验证 REQ-SW-001-005）
前提：新软件的档案保存成功，随后文件步骤失败。
操作：提交软件与首个版本。
结果：软件仍可在后台查询，页面明确提示版本失败，不宣称版本已成功添加。
