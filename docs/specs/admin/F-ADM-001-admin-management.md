## 目标与范围

定义管理员登录、管理会话、分类/平台/标签、软件档案、图片与截图相册、发布状态、草稿预览、看板、导航和正文编辑。版本物理文件和下载生命周期由 F-DST-001 负责，公开展示由 F-CAT-001 负责。

## 基线决策与证据

本 Spec 采用“代码优先的正式现状基线”。用户已明确确认：本阶段未单独确认的行为，以当前代码、当前前端消费者、数据模型、Docker 输入和发布脚本实际表达的行为为准。该确认包括当前实现中已经存在的限制和缺陷；它们不会被伪装成已修复功能。

本文件中的 REQ/AC 用于记录本能力的稳定边界和可追溯验收口径；与当前实现存在差异的历史目标，按下方“已知问题备注”处理，暂不作为本阶段已完成能力。后续要改变行为，必须建立新的 Change，更新 REQ/AC、契约、消费者和验证证据。

## 规范性需求（当前正式基线）

### REQ-ADM-001-001
当管理员提交正确全局密码时，系统必须签发符合当前 issuer/audience、配置有效期和签名规则的 JWT；错误密码返回 HTTP 200、业务 code=401 且无有效 token。当前正式基线保留单管理员 JWT/localStorage 会话，不同时引入 Cookie 会话。
来源：PRD:9、33；AuthController / AuthService；取舍 D3

### REQ-ADM-001-002
当未携带有效 JWT 的请求访问管理 API 时，服务端必须拒绝；前端缺失令牌跳转登录，服务端 401 或本地退出清除令牌并返回登录页。前端只检查存在性不等于已验证令牌有效。
来源：当前路由守卫、Axios 与 JwtBearer

### REQ-ADM-001-003
当管理员创建分类时，系统必须保存非空名称、存在或为空的父分类和 SortOrder；同级按 SortOrder、CreatedAt、Id 稳定排列，允许创建任意深度而不产生环。
来源：PRD:37；CategoryService.CreateAsync/BuildTree

### REQ-ADM-001-004
当管理员创建平台时，系统必须保存名称、可选 IconClass/ColorHex 和 SortOrder，拒绝空白或已有同名平台；空可选字段存 null，不把任意图标/颜色值执行为脚本。
来源：PRD:38；PlatformService.CreateAsync

### REQ-ADM-001-005
当管理员创建软件档案时，系统必须保存名称、简介、正文、图标、官网、分类、单平台、标签和 Published/Draft 状态；分类/平台/标签引用必须有效，空可选引用允许为 null。
来源：PRD:40–43；SoftwareCreateRequest；取舍 D1、D2

### REQ-ADM-001-006
当管理员打开看板时，系统必须显示软件数、版本记录数、分类数、平台数、版本 FileSize 总和的逻辑空间（Bytes）及现存版本 DownloadCount 总和；零数据返回 0，逻辑空间不宣称等于 NAS 实际占用或全生命周期累计。
来源：PRD:34；当前 DashboardService；明确逻辑统计口径

### REQ-ADM-001-007
当管理员上传图标或编辑器/截图图片时，系统必须验证合法图片内容及现有 10 MB 控制器上限，使用服务器生成存储名保存于上传根目录，返回 /uploads 下资源引用；失败不留下本次临时文件。
来源：PRD:42；AdminSoftwaresController.UploadImage

### REQ-ADM-001-008
当管理员编辑分类父级或排序时，系统必须拒绝直接或间接循环、未知父级和空白名称；合法修改更新整棵树的可达关系，不修改其下软件实体 ID。
来源：CategoryService.UpdateAsync；间接环现状缺口

### REQ-ADM-001-009
当管理员删除分类时，系统必须拒绝有子分类的节点；删除无子分类节点时保留软件并把其 CategoryId 置空，不删除软件文件。
来源：当前 Restrict / SetNull 数据关系

### REQ-ADM-001-010
当管理员编辑平台时，系统必须保留平台 ID，更新名称/图标/颜色/排序并拒绝与其他平台同名；软件关联保持指向原平台。
来源：PlatformService.UpdateAsync

### REQ-ADM-001-011
当管理员删除平台时，系统必须保留关联软件并清空其 PlatformId；不存在的平台返回 404，不删除软件包。
来源：PlatformService.DeleteAsync / SetNull

### REQ-ADM-001-012
当管理员创建或编辑标签时，系统必须保存非空且不与其他标签重复的名称与可选颜色；编辑保留标签 ID 及已有关联，标签列表按 Name、CreatedAt 排列。
来源：TagService / TagCreate/UpdateRequest

### REQ-ADM-001-013
当管理员删除标签时，系统必须只删除标签及 SoftwareTag 关联，不删除软件、版本或文件；不存在标签返回 404。
来源：TagService.DeleteAsync / 多对多级联

### REQ-ADM-001-014
当管理员保存软件标签集合时，系统必须用请求中的有效 TagIds 替换该软件的关联集合并消除重复 ID；空集合清除关联，未知 ID 拒绝整次修改。
来源：SoftwareService Create/Update 标签替换

### REQ-ADM-001-015
当管理员查询软件列表时，系统必须包含 Published 与 Draft 软件，支持分类、平台、标签、关键词、排序和分页组合，分页边界引用 REQ-CAT-001-008，空结果及失败有明确反馈。
来源：后台列表与 AdminSoftwaresController

### REQ-ADM-001-016
当管理员编辑软件档案时，系统必须更新 REQ-ADM-001-005 的相同字段规则并保留软件 ID、CreatedAt、已关联版本和计数；正文编辑遵循 REQ-ADM-001-026。
来源：SoftwareUpdateRequest / SoftwareService.UpdateAsync

### REQ-ADM-001-017
当管理员创建或改名软件时，系统必须在服务端写入阶段约束同一 PlatformId（含空平台）下的软件名唯一；前端 check-name 仅为提示，不能替代并发写入约束。
来源：当前前端预检查，服务/数据库强约束缺失

### REQ-ADM-001-018
当管理员切换软件发布状态时，系统必须只接受 Published/Draft；Draft 软件及其版本所有公开入口均执行 REQ-CAT-001-007 的限制，管理员仍可维护记录，不强行重写每个版本的独立可见状态。
来源：PRD:43；ChangeStatusRequest；发布边界

### REQ-ADM-001-019
当管理员删除软件时，界面必须明确确认涉及的软件、版本及资源范围；文件清理失败时报告失败并保留可追溯记录，不对仍被其他软件引用的图片/文件执行删除。资源清理遵循 REQ-DST-001-013 的根目录边界。
来源：当前 SoftwareService.DeleteAsync 异常吞掉边界

### REQ-ADM-001-020
当管理员维护独立截图相册时，系统必须允许添加、移除和排序已上传图片与该软件的关联；图片上传和关联保存分别报告结果，不以正文图片替代相册。
来源：PRD:22、42；SoftwareScreenshot/SortOrder

### REQ-ADM-001-021
当管理员查看下载 Top 10 时，系统必须按软件 TotalDownloads 降序、Id 升序返回最多 10 项，包含软件名和计数；包含管理范围内 Published/Draft 软件，零数据返回空榜单。
来源：PRD:35；当前看板无排行接口

### REQ-ADM-001-022
当管理员退出时，页面必须删除本浏览器保存的管理令牌、停止继续发送该令牌并导航登录；退出不宣称已撤销此前签发 JWT 在其他设备上的服务端有效期。
来源：当前 localStorage / AdminLayout 退出

### REQ-ADM-001-023
当生产环境进行初始化或访问模板接口时，系统必须禁止匿名 seed 写入，初始化只能在明确授权的管理上下文或隔离开发环境执行；WeatherForecast 等模板 API 不作为生产产品入口。
来源：当前匿名 seed / 可达 WeatherForecast

### REQ-ADM-001-024
当管理员预览软件时，页面必须使用授权的管理读取能力支持 Draft 预览，保留公开权限规则；不得通过临时公开草稿或绕过公开 API 来实现预览。
来源：当前预览 window.open 公开详情，草稿被拒绝

### REQ-ADM-001-025
当管理员使用后台导航或登录输入时，界面必须提供当前页面位置、可达的软件/文件/字典入口，允许 Enter 提交登录并展示真实失败信息；登录流程仍只有全局密码，不引入用户名。
来源：UIUX:70–76；Login.vue / AdminLayout

### REQ-ADM-001-026
当管理员编辑软件正文时，编辑器必须允许现有标题、列表、引用、代码、链接以及图片粘贴/上传、尺寸与对齐操作，保存 Tiptap HTML；图片上传失败保留编辑内容并显示错误，展示端安全规则引用 REQ-CAT-001-010。
来源：RichEditor.vue 的现有扩展与图片操作；正文格式取舍 D2

## 质量与边界

管理 API 必须由服务端鉴权，前端令牌存在性不能代替服务端授权；字典和关联操作需保留数据完整性；上传、删除、初始化、模板接口的失败必须可追溯。

## 各端和契约关系

接口和 DTO 的当前入口见 [HTTP 契约参考](../../contracts/http-api.md)。后端控制器、请求/响应 DTO、EF 模型和迁移是当前实现事实的权威来源；本 Spec 的 REQ/AC 是目标行为来源。涉及跨端的需求必须同时核对 API、消费者、持久化和错误处理。

## 必要技术说明

当前后端采用 ASP.NET Core JWT Bearer、EF Core SQLite、`ApiResponse<T>`；前端 Axios 从 localStorage 附加 Bearer 并在 401 时清除。`Software.PlatformId` 是单值，截图实体已存在但写入链路需补齐。看板当前只有基础计数，空间/Top10 目标按明确统计口径定义。

## 验收场景

### AC-ADM-001-001（验证 REQ-ADM-001-001）
Given 隔离环境配置密码与 JWT 密钥
When 分别提交正确与错误密码
Then 正确请求得到 token；错误为 HTTP 200/code 401 且没有可用 token，不泄漏密码/密钥

### AC-ADM-001-002（验证 REQ-ADM-001-002）
Given 无令牌、过期、篡改及有效令牌
When 访问管理页和管理 API
Then 前三类无管理读写权限；HTTP 401 清除本地令牌；有效项可操作；浏览器修改 localStorage 不能获得服务端权限

### AC-ADM-001-003（验证 REQ-ADM-001-003）
Given 已有分类 A 和空数据库分支
When 创建 A 下的 B 和根分类，再提交不存在父 ID
Then 合法节点进入对应树层与排序；无效父请求被拒绝且无孤立记录

### AC-ADM-001-004（验证 REQ-ADM-001-004）
Given 平台 Windows 已存在
When 重复创建 Windows，另创建名称有效且可选字段空的平台
Then 重复/空白名称被拒绝，合法新项保存，可选字段为 null，无脚本执行

### AC-ADM-001-005（验证 REQ-ADM-001-005）
Given 有效字典与已登录管理员
When 创建合法软件，再提交未知字典 ID/非法状态/空白名称
Then 合法字段和关联持久化；非法请求拒绝，不产生部分软件/关联记录

### AC-ADM-001-006（验证 REQ-ADM-001-006）
Given 2 个软件、3 个版本，FileSize 为 10/20/30，DownloadCount 为 1/2/3
When 查询并显示看板
Then 软件数2、版本数3、逻辑空间60 Bytes、现存版本计数6；前端实际显示版本/空间卡片；空库各值0

### AC-ADM-001-007（验证 REQ-ADM-001-007）
Given 小于上限的合法图片、伪造扩展名文件与超限文件
When 分别上传
Then 合法项可由返回引用读取；非法/超限被拒绝，无可执行脚本文件或本次残留资源

### AC-ADM-001-008（验证 REQ-ADM-001-008）
Given A→B→C
When 把 A 父级设为 C、自身或未知 ID，再把 C 移到根
Then 前三次拒绝且原树保留；合法移动树可遍历，软件 ID 不变

### AC-ADM-001-009（验证 REQ-ADM-001-009）
Given 一个有子节点分类及一个关联软件的叶子分类
When 分别删除
Then 有子项拒绝；叶子删除后软件仍在、分类为空、文件未动

### AC-ADM-001-010（验证 REQ-ADM-001-010）
Given 平台 P1 和 P2，软件关联 P1
When 改 P1 名称为 P2，再合法改名
Then 冲突被拒绝；合法编辑不改变平台 ID 或软件关联

### AC-ADM-001-011（验证 REQ-ADM-001-011）
Given 软件关联 P1
When 删除 P1 并再次请求删除
Then 软件保留、平台为空、包保留；再次请求 404

### AC-ADM-001-012（验证 REQ-ADM-001-012）
Given 标签 A、B 且软件关联 A
When 创建重复 A、将 A 改为 B，再合法修改 A 颜色
Then 冲突拒绝；合法操作保留 A 的 ID/关联并更新颜色，列表排序可复核

### AC-ADM-001-013（验证 REQ-ADM-001-013）
Given 两个软件关联同一标签
When 删除标签
Then 两软件及其版本/包保留，关联移除；不存在标签返回 404

### AC-ADM-001-014（验证 REQ-ADM-001-014）
Given 软件已有标签 A、B，另有 C
When 保存 C,C，再保存空集合和未知 ID
Then 首次只关联 C 一次；空集合移除关联；未知请求拒绝且上次结果保留

### AC-ADM-001-015（验证 REQ-ADM-001-015）
Given 公开/草稿软件分属分类、平台与标签
When 组合筛选并翻页，另模拟请求失败
Then 结果和 total 对应条件，草稿可被管理；失败可重试，不丢失已输入筛选

### AC-ADM-001-016（验证 REQ-ADM-001-016）
Given 带版本与计数的软件
When 合法修改元数据，再提交无效引用
Then 合法结果保留身份/版本/计数；无效请求不产生部分更新

### AC-ADM-001-017（验证 REQ-ADM-001-017）
Given 同平台已有软件，另有不同平台的软件
When 同平台并发创建相同名称，另跨平台同名创建
Then 同平台最多一项成功，其余冲突拒绝；不同平台同名允许；编辑自身不误报冲突

### AC-ADM-001-018（验证 REQ-ADM-001-018）
Given 已发布软件有可见与隐藏版本
When 下架并直接查询/下载，后台编辑后重新上架
Then 下架时公开入口拒绝；后台可管理；重新上架仅独立可见项可公开，隐藏项不被自动公开

### AC-ADM-001-019（验证 REQ-ADM-001-019）
Given 软件有版本/图片，部分资源共享且一份文件无删除权限
When 确认删除
Then 共享资源不删；无法完成的删除明确失败，不伪报全部清理成功，数据可供修复重试

### AC-ADM-001-020（验证 REQ-ADM-001-020）
Given 已上传三张图片与一个软件
When 添加三张、调整排序、移除一张，再查看公开详情
Then 关联和顺序持久化，公开相册剩两张；未保存关联的上传不伪报软件相册已更新

### AC-ADM-001-021（验证 REQ-ADM-001-021）
Given 12 份软件含并列计数和草稿
When 查看排行榜及空库榜单
Then 返回按规则排列的前10项，并列稳定；草稿按管理范围包含，空库无伪造榜单

### AC-ADM-001-022（验证 REQ-ADM-001-022）
Given 已登录浏览器和已签发 JWT
When 退出后访问管理页/发新请求
Then 本地令牌清除，新请求不携带它且回登录；不产生虚假的全设备注销声明

### AC-ADM-001-023（验证 REQ-ADM-001-023）
Given 生产配置和隔离开发配置
When 匿名访问 seed 和模板入口，再在授权初始化上下文操作
Then 生产匿名请求不能写库或暴露模板入口；隔离/授权初始化有明确执行记录

### AC-ADM-001-024（验证 REQ-ADM-001-024）
Given Draft 软件和未登录浏览器
When 管理员预览，再由未登录者访问相同入口
Then 管理员可读预览；未登录者拒绝；软件未被临时上架，公开详情仍 404

### AC-ADM-001-025（验证 REQ-ADM-001-025）
Given 无令牌登录页及已登录后台
When 按 Enter 提交错误/正确密码并切换管理入口
Then 错误留在登录页显示原因，正确进入后台；各入口可到达且页面位置可辨识

### AC-ADM-001-026（验证 REQ-ADM-001-026）
Given 包含文本格式和图片的编辑内容
When 修改格式、图片尺寸对齐、保存并重新打开，再模拟上传失败
Then 内容与支持格式保留；详情可读；上传失败不清空已有正文或伪报图片成功
