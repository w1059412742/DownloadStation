## 功能规则

### REQ-软件库-001-001：软件库边界
软件安装包的扫描、绑定、上传、下载读取和删除必须限于配置软件库内；外部路径不得因管理员输入、自定义扫描目录、软件名或文件名绕过该边界。库外操作必须被拒绝，不得扫描库外内容、创建库外版本绑定或写入/读取/删除库外安装包。

### REQ-软件库-001-002：未绑定文件扫描
对于库内存在且可读的目录，扫描必须递归列出物理文件，排除已绑定版本的路径，返回未绑定文件的名称、路径和字节大小。当前顺序扫描的路径匹配采用斜杠统一后的字符串相等；路径别名/大小写/相对绝对形式的去重缺口见B04，不据此承诺等价路径已统一。

### REQ-软件库-001-003：目录缺失与手工绑定
默认软件库目录缺失时，扫描必须创建默认目录；指定库内自定义目录不存在时必须返回空列表而不创建该目录。库内有效文件必须能通过软件编辑页提供软件、版本号、日志及路径进行手工绑定；成功后的结果引用版本规格，不在本处重定义。

## 扫描和绑定的处理逻辑

1. 管理员进入`/admin/files`输入可选扫描路径并显式执行扫描；空值或纯空白使用StorageBasePath，未配置时为`./SoftwareStorage`，非空值使用指定目录，但必须先满足REQ-软件库-001-001的库内边界。默认目录与自定义目录的缺失分支按REQ-软件库-001-003执行。
2. 对存在可读目录递归枚举文件；将枚举路径及全部已绑定版本路径中的反斜杠统一为`/`，以区分大小写的字符串相等排除已绑定项。任一版本的绑定都参与排除，包含隐藏记录，不只检查当前软件或默认版。返回每个剩余文件的文件名、统一斜杠的路径及字节大小；不承诺枚举结果的排序。
3. 扫描成功替换页面文件列表，解除加载状态；扫描不是持续监控，也不创建版本或移动文件。页面扫描请求失败必须提示响应message，无message时提示检查路径/权限；目录拒绝、扫描中文件变化时的服务恢复和部分结果策略仍未确认，不新增其正确目标。
4. 扫描页“关联到软件”按钮当前只提示开发中，不代表绑定流程完成。手工绑定须进入软件编辑页，提供软件ID、版本号、可选日志及路径；成功创建的记录和默认变化引用版本规格。绑定失败显示响应错误，目录/文件与数据库跨操作的一致性依旧是B04。

## 验收条件

### AC-软件库-001-001（验证 REQ-软件库-001-001）
前提：隔离库内外各有一个无敏感内容的临时文件。
操作：请求库外扫描、绑定、下载及删除；尝试用派生路径写到库外。
结果：全部拒绝，库外目录/文件不变，无库外绑定记录，不返回库外文件内容。

### AC-软件库-001-002（验证 REQ-软件库-001-002）
前提：库内目录与子目录各有文件，其中一路径已绑定且表示形式一致。
操作：扫描该目录。
结果：返回所有未绑定文件及准确字节数，不包含已绑定文件；扫描本身不创建版本记录。

### AC-软件库-001-003（验证 REQ-软件库-001-003）
前提：默认库目录缺失，另有库内不存在的自定义子目录和一个库内有效文件。
操作：依次扫描默认目录、自定义目录，再手工绑定文件。
结果：默认目录被创建；自定义目录返回空且仍不存在；绑定生成版本并符合版本规格。
