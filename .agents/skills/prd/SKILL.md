# 个人专属软件下载站需求规格说明书 (PRD)

## 1. 项目概述
本项目旨在群晖 NAS 环境下，构建一个专属于个人的软件安装包管理与分发平台。
系统提供干净、无广告的 Web 页面供访客检索和高速下载软件；同时提供一个受固定密码保护的管理后台。系统核心特色在于深度结合 NAS 局域网大文件管理的便利性，通过“SMB 传文件 + Web 端扫描绑定”的创新工作流，实现极简的软件发布体验。

## 2. 用户角色划分
- **访客 (Visitor)**： 无需登录。可浏览公开的软件目录、查看图文详情、比对校验码并直接下载文件。
- **管理员 (Admin)**： 站长本人。通过全局固定密码登录后台，拥有站点的所有内容管理权限。

## 3. 前台展示端需求 (Public UI)

### 3.1 首页与检索 (软件大厅)
- **无限层级分类导航**： 提供侧边栏或顶部导航，展示无限层级的软件分类树。用户点击任意节点，均可筛选出该节点及其所有子节点下的软件。
- **多维标签与排序**：
    - **平台过滤**： 提供直观的操作系统平台标签（如 Windows, macOS, Android），支持点击快速过滤。
    - **动态排序**： 软件列表支持按“最新更新时间”或“最热下载量”进行切换排序。
- **全局搜索**： 提供搜索框，支持通过软件名称或简介进行模糊检索。
- **软件列表展示**： 以卡片或列表形式展示，包含：软件图标、名称、一句话简介、支持的平台图标、总下载次数。

### 3.2 软件详情页
- **基础信息区**： 展示软件高清图标、名称、所属分类、官方网站链接、软件总下载量。
- **图文介绍区**： 支持 Markdown 格式的富文本渲染（用于展示详细功能、安装教程、注意事项等）。
- **截图相册区**： 展示多张软件界面截图，支持点击放大查看（Lightbox 灯箱效果）。

### 3.3 版本列表与下载区 (核心)
- **版本列表展示**：
    - 以时间倒序（最新在最前）列表展示可用版本。
    - 包含字段：版本号、更新时间、文件大小、安全校验码（MD5/SHA256）、单版本下载次数。
- **更新日志 (Changelog)**： 每个版本均可点击展开“更新日志”，展示该版本的具体更新说明（支持 Markdown 排版）。
- **历史版本折叠 (Archive)**： 默认只展示最新的 3 个版本，其余较老的版本自动折叠，提供“查看更多历史版本”按钮供用户展开查阅。
- **下载操作**： 提供醒目的【下载】按钮，点击直接触发文件下载流。系统需同时在后台对该版本的“下载次数”执行 +1 操作。

## 4. 后台管理端需求 (Admin UI)

### 4.1 安全与控制台看板 (Dashboard)
- **极简登录**： 访问后台需输入全局固定密码，登录后保持会话（Cookie），未登录自动拦截。
- **数据看板**： 登录后首屏展示站点宏观数据：总软件数、总版本/文件数、总占用存储空间、总累计下载次数。
- **排行榜单**： 看板中展示“全站下载量 Top 10”的热门软件列表。

### 4.2 基础字典管理 (元数据)
- **分类管理 (Category)**： 支持新建、编辑、删除分类；支持指定父级分类，构成无限层级的树状结构。
- **平台管理 (Platform)**： 管理系统平台标签，可自定义平台名称、显示颜色或内置的图标类名。

### 4.3 软件档案管理 (Software CRUD)
- **基础录入**： 填写软件名称、一句话简介、官方网站链接。
- **分类与平台**： 选择所属分类（单选，支持选入任意层级），勾选支持的平台（多选）。
- **图文维护**： 上传软件图标（单图），上传软件截图（多图），使用 Markdown 语法编写详细描述。
- **状态控制**： 软件支持“上架 (Published) / 下架 (Draft)”状态。下架的软件及关联版本在前台完全隐藏。

### 4.4 版本与文件管理 (NAS联动核心机制)
- **NAS 未绑定文件扫描 (神技)**：
    - 提供【扫描本地目录】功能。系统自动遍历 NAS 的专属软件存储文件夹。
    - 比对数据库，列出所有“已存在于硬盘，但尚未入库”的孤儿文件。
    - 管理员可直接在列表中点击【一键入库】，弹出绑定弹窗。
- **版本录入与绑定**：
    - 为某个软件添加新版本时，需指定版本号（如 v2023.1）并关联 NAS 中的实际文件。
    - 填写该版本的“更新日志 (Changelog)”。
- **自动化信息提取与哈希计算**：
    - 文件绑定成功后，系统自动读取并记录文件的真实大小（Bytes）。
    - 系统在后台自动计算该文件的安全校验码（如 SHA256），并持久化保存。
- **版本状态与删除机制 (软/硬删除)**：
    - 支持单版本的“显示/隐藏”切换。
    - 删除版本时提供选项：
        1. 仅删除系统记录（历史归档，保留 NAS 硬盘上的物理文件）。
        2. 彻底删除（同时删除数据库记录和 NAS 硬盘上的物理文件，释放空间）。

## 5. 核心工作流描述 (Admin 视角)
1. **传文件**： 你在个人电脑上下载了一个镜像。你打开局域网的“网上邻居(SMB)”，直接将文件拖入群晖 NAS 的专属文件夹中。传输飞快。
2. **扫文件**： 你打开下载站的 Web 后台，进入“版本管理”，点击【扫描本地目录】。
3. **绑软件**： 系统立刻发现了刚才拖入的镜像文件。你点击该文件旁边的【入库】，在弹窗中选择归属软件，输入版本号，填入更新日志，点击保存。
4. **自动化**： 系统瞬间保存，并在后台默默计算出了文件的 SHA256 校验码，同时提取了精确的文件大小。
5. **发布完成**： 访客此时刷新前台页面，就能看到软件顶上冒出了最新版本，附带更新说明和防篡改校验码，点击即可满速下载。
