# 个人专属软件下载站前端界面设计规范 (UIUX)

## 1. 设计理念 (Design Philosophy)
- **克制与留白 (Less is More)**： 放弃边框线，依靠充足的留白 (Spacing) 和柔和的背景色差来划分区域。
- **内容优先 (Content First)**： UI 应当隐退，突显软件图标、名称和排版。
- **优雅灵动 (Fluid & Elegant)**： 拒绝生硬的颜色切换，所有悬停、展开、页面跳转均需包含 0.2s - 0.3s 的缓动过渡动画 (Ease-in-out)。
- **扁平化导航 (Flat Navigation)**： 彻底抛弃深层级的树状目录，采用“平铺胶囊式”或“双重顶导”实现 1-2 级分类的高效检索。

## 2. 全局设计系统 (Design System)

### 2.1 色彩规范 (Color Palette)
摒弃大红大绿，采用高级灰调与单一强调色。
- **背景色 (Background)**：
    - 亮色模式：纯白 #FFFFFF (卡片/内容区) / 极浅灰 #F8FAFC (底层背景)。
    - 暗色模式：深空灰 #0F172A (底层背景) / 炭灰 #1E293B (卡片/内容区)。
- **文字色 (Typography Colors)**：
    - 一级标题 (H1/H2)：纯黑 #0F172A (亮) / 纯白 #F8FAFC (暗)。
    - 正文描述 (Body)：浅石板灰 #64748B (亮) / #94A3B8 (暗)。
- **强调色 (Primary Accent)**：
    - 推荐使用 克莱因蓝 #0055FF 或 苹果靛蓝 #5E5CE6。仅用于主【下载】按钮、选中状态的分类标签、以及文字超链接。

### 2.2 阴影与圆角 (Shadows & Radius)
- **无边框主义**： 卡片默认不要 border: 1px solid，而是使用弥散阴影。
- **卡片阴影 (Card Shadow)**： `box-shadow: 0 10px 40px -10px rgba(0,0,0,0.08);` (极大、极柔和的阴影)。
- **圆角规范 (Border Radius)**：
    - 按钮、小标签 (Pills)：8px 或 9999px (全圆角)。
    - 软件展示卡片：16px。
    - 大型对话框/详情图片：24px。

### 2.3 字体排版 (Typography)
- **字体族 (Font Family)**： Inter, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif;
- **字重对比**： 标题使用 font-weight: 700 (Bold)，描述使用 font-weight: 400 (Regular)。

## 3. 前台展示页设计规范 (Public UI)
前台布局采用全宽顶部导航 + 居中限制宽度的内容区（最大宽度 1200px）。

### 3.1 顶部导航栏 (Header)
- **视觉效果**： 采用“毛玻璃”特效 (`backdrop-filter: blur(12px); background: rgba(255,255,255,0.7)`)。
- **布局 (三段式)**：
    - Left: 极简的 Logo + 站点名称。
    - Center: 宽大、圆角、浅灰背景搜索框。
    - Right: 太阳/月亮切换暗黑模式。

### 3.2 软件大厅 (首页 Index)
- **头图欢迎区 (Hero Section)**： 顶部留白 80px，居中大标题及灰色小字。
- **分类导航区 (Category Pills)**： 
    - 一级分类：居中横向排列，选中项加粗并带下划线动画。
    - 二级分类：灰色胶囊按钮 (Pills)，选中变为主色。
- **软件列表区 (Bento Box 网格)**： 采用 CSS Grid 布局，悬停时卡片浮动且阴影加深。
    - 内容：64x64px 图标、粗体软件名、两行简介、底部平台与下载量。

### 3.3 软件详情页 (Detail)
- **阅读区限宽**： 主体内容限制在 800px，居中。
- **环境光背景 (Ambient Header)**： 提取图标主色调作为顶部模糊背景。
- **Markdown 正文区 (Prose)**： 行高 1.75，提供代码块一键复制。
- **版本与下载区 (卡片栈排列)**：
    - 最新版本：带细微主色边框，醒目下载按钮，校验码默认隐藏。
    - 历史版本：时间线列表形式，默认折叠。

## 4. 后台管理页设计规范 (Admin UI)

### 4.1 极客登录入口 (Login)
- **视觉**： 纯黑或纯白背景，中心只有一个输入框。输入正确密码后按 Enter 键淡出进入后台。

### 4.2 整体布局 (Layout)
- **侧边栏 (Sidebar)**： 窄栏设计，使用线条风格图标。
- **内容区 (Main)**： 纯白背景，带面包屑导航。

### 4.3 扫描入库流程界面 (核心交互)
- **界面布局**： 左右分栏或抽屉式 (Drawer)。
- **交互流**： 扫描发现文件 -> 点击入库 -> 右侧滑出抽屉 -> 表单预填充 -> 保存并计算校验码 -> 列表项带成功动画消失。
